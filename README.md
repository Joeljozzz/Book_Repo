This repository serves as a personal digital reference shelf for in-depth technical study, certification preparation, and engineering best practices.

## 📖 Curated Collection

| Subject Area | Book Title | Authors | Edition | Focus Areas |
| :--- | :--- | :--- | :---: | :--- |
| **Artificial Intelligence** | *Artificial Intelligence: A Modern Approach* | Stuart Russell & Peter Norvig | 3rd Ed. | Search algorithms, knowledge representation, probabilistic reasoning, machine learning |
| **Data Science & Statistics** | *An Introduction to Statistical Learning (ISLR)* | Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani | 2nd Ed. | Regression, classification, resampling methods, tree-based models, unsupervised learning |

## 🚀 Getting Started

### Cloning the Repository

Because this repository contains large PDF reference files (~42 MB total), a shallow clone is recommended to save bandwidth and storage:

```bash
# Shallow clone (latest commit only)
git clone --depth 1 https://github.com/Joeljozzz/Book_Repo.git

# Navigate into the directory
cd Book_Repo
```

### Viewing Documents

All materials are provided in standard PDF format and can be viewed using any PDF reader (such as Adobe Acrobat, SumatraPDF, Foxit Reader, or modern web browsers like Chrome, Edge, and Firefox).
