# 📚 Book_Repo

A curated collection of **books, PDFs, and learning materials** on **Data Science**, **Software Development**, and **Software Testing**.  
This repository serves as a **personal digital library** — a one-stop resource for learners, developers, and testers who want to deepen their technical knowledge.

---

## 🧩 **Repository Overview**

This repo contains categorized folders with books and references across three main domains:

### 🧠 Data Science
- Machine Learning, Deep Learning & AI
- Data Analysis & Visualization
- Python for Data Science
- Statistics and Probability

### 💻 Software Development
- Programming Languages (Python, C, C++, Java)
- Software Design & Architecture
- Web Development
- Clean Code and Best Practices

### 🧪 Software Testing
- Manual Testing Concepts
- Automation Testing (Selenium, PyTest, etc.)
- QA Frameworks and Methodologies
